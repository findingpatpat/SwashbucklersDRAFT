# 100 Yard Draft Race v4

New in this version:

- SPACE (or the blue THROW button) throws a football at the nearest racer within 12 yards.
- A football hit causes a short 0.5-second stumble.
- Hit the same racer 3 consecutive successful times to earn one blocker.
- Missing, being blocked, or switching targets breaks/changes the streak.
- A blocker absorbs one incoming football and then disappears.
- Maximum 3 blockers per racer.
- Existing LEFT/RIGHT running and UP/DOWN adjacent-lane body checks remain.
- Race remains tuned to roughly 60 seconds.
- When everyone disconnects, the game automatically resets to a fresh lobby.

To update Render, replace your existing repo files with these files and push the commit.
